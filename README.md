# 🎓 Edventure

A fun and interactive mobile learning app designed for kids, combining education with engaging game-based activities.

## 🔧 Tech Stack
- **Framework:** Flutter
- **Language:** Dart

## ✨ Features
- **Multiple Game Modes** — Puzzles, MCQs, Riddles, Fill-in-the-Blanks, and True/False
- **Randomised Questions** — Game modes are mixed randomly to keep kids engaged
- **Multi-Subject Coverage** — Math, Science, and English
- **Kid-Friendly UI** — Simple, colourful interface designed for early learners

## 🎯 Purpose
Edventure was built to make learning enjoyable for young children by turning education into a game, covering core school subjects in a playful format.

## 📱 Platform
- Android (tested on a physical Android device)
